# Documentation versions

One folder per major version of `offline-agency/filament-spid`. The newest is
the current one.

| Version | PHP | Laravel | Filament | Documentation |
|---|---|---|---|---|
| 1.x (current) | ^8.3, tested on 8.3, 8.4, 8.5 and 8.6 | ^12.0 \| ^13.0 | ^3.0 \| ^4.0 \| ^5.0 | [v1/index.md](v1/index.md) |

0.1.x is no longer maintained and has no documentation folder: see
[upgrading from 0.1.x](v1/upgrading.md).

`publication/` holds maintainer notes (release announcement, plugin directory
submission, GitHub About text) and is not part of any version.
